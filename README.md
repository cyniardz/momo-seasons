# Momo's Four Seasons

**계절마다 옷을 갈아입는 곰 인형, 모모의 사계절.**

곰 인형 캐릭터 **모모**를 소개하는 한 화면 인터랙션 웹사이트입니다.
페이지가 아래로 내려가지 않고, 한 무대 위에서 장면만 바뀝니다. 첫 화면에서 계절을 넘기면 모모의 옷과 배경색, 떠다니는 소품이 함께 바뀌고, 고른 계절이 소개·사진첩·피드까지 따라갑니다.

- Live: https://momo-seasons.vercel.app
- Figma 프로토타입: (작업 후 링크 추가) · [docs/figma-prototype.md](docs/figma-prototype.md)
- 기간: 2026.11.11 – 11.14 (4일, 1인)
- 역할: 기획, UI 디자인, 퍼블리싱 (100%)

## 기획 배경

| 구분 | 내용 |
| --- | --- |
| 문제 | 캐릭터 소개 페이지는 이미지, 설정표, 굿즈 목록이 아래로 길게 이어진다. 캐릭터를 느끼기 전에 스크롤만 하다 나간다. |
| 제안 | 한 화면에 세우고 계절을 갈아입힌다. 화면은 그대로, 내용만 바뀐다. |
| 핵심 경험 | 첫 화면에서 계절을 고르고, 모모가 갈아입는 걸 보고, 눌러서 반응을 본다. |
| 이어지는 경험 | 고른 계절이 소개, 사진첩, 인스타그램 피드까지 따라간다. |

### 사용자 흐름

```
첫 화면 (계절 고르기) → 모모 소개 → 굿즈 → 사진첩 → 이야기
        ↑ 고른 계절이 모든 장면의 색과 이미지를 정한다
```

### 계절 모모 네 벌

| 계절 | 옷과 소품 | 한마디 | 색 |
| --- | --- | --- | --- |
| 봄 | 분홍 보닛, 노란 가디건, 벚꽃 가지 | 벚꽃 보러 같이 갈래? | `#C4426F` |
| 여름 | 밀짚 보닛, 선글라스, 꽃무늬 셔츠, 수박바 | 수박바는 양보 못 해. | `#1673C9` |
| 가을 | 머스터드 보닛, 트렌치코트, 커피 | 커피 한 잔 들고 좀 걷자. | `#B44F1C` |
| 겨울 | 털 보닛, 목도리, 털부츠, 선물 | 네 선물도 준비했어. | `#145640` |

털, 분홍 볼, 턱 아래 리본 매듭은 계절이 바뀌어도 그대로 둡니다. 네 이미지는 같은 구도로 만들어, 계절을 바꾸면 제자리에서 옷만 갈아입은 것처럼 보입니다.

## 화면 구성

| 장면 | 내용 |
| --- | --- |
| 첫 화면 | 계절 이름과 한마디, 가운데 모모, 소품 6개. 화살표·점·키보드·스와이프로 계절 전환 |
| 모모 소개 | 모모가 왼쪽 칸으로 떨어져 앉고, 오른쪽에 프로필과 "모모를 알아보는 네 가지" (지금 계절 모모를 확대) |
| 굿즈 | 인형, 키링, 머그 등 6종 (계절과 상관없이 같음) |
| 사진첩 | 지금 계절 사진 4장과 인스타그램 피드 미리보기 (고정 게시물 + 지금 계절 게시물만) |
| 이야기 | 계절마다 하나씩 하는 일, 팔로우 안내와 푸터 |

## 주요 인터랙션

- **계절 전환** — 화면이 1.38배 부풀며 -14° 도는 사이 모모가 옷을 갈아입고, 소품 6개가 계절마다 정해진 자리로 날아감
- **장면 전환** — 휠 약 두 칸, ↑↓ 키, 세로 스와이프, 메뉴. 장면 안에 더 읽을 내용이 있으면 그 안에서 먼저 스크롤
- **모모 착지** — 소개 장면으로 가면 모모가 위에서 떨어져 왼쪽 칸에 정착
- **모모 점프** — 첫 화면에서 모모를 누르면 폴짝
- **마우스 패럴랙스** — 소품이 크기(깊이)에 비례해 마우스 반대쪽으로 움직임
- **계절 따라가기** — 소개의 네 가지 특징, 사진첩, 피드, 프로필 사진이 `data-season` 하나로 바뀜 (CSS 변수 `--momo`)
- **메뉴 표시** — 지금 장면 메뉴만 선명하게, 나머지는 흐리게
- **움직임 줄이기** — `prefers-reduced-motion` 설정이면 애니메이션 없이 바로 전환

- HTML / CSS / JavaScript (프레임워크·라이브러리 없음)
- 폰트: Pretendard Variable (jsDelivr)

## 폴더 구조

```
momo-seasons/
├── index.html      # 장면 5개 구조
├── style.css       # 디자인, 장면 전환, 계절별 이미지
├── js.js           # 계절 전환, 장면 전환, 소품 배치, 입력 처리
├── favicon.ico
├── apple-touch-icon.png
├── docs/
│   └── figma-prototype.md   # Figma 계절 전환 프로토타입 만드는 법
└── img/
    ├── spring/ summer/ autumn/ winter/
    │   ├── momo-<계절>.png  # 계절 모모 (같은 구도)
    │   ├── <계절>-0~5.png   # 떠다니는 소품 6개
    │   ├── g-<계절>.jpg     # 사진첩·피드 사진
    │   └── (계절 사진 3장)
    └── product_*.png        # 굿즈
```
