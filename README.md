# 모모의 사계절 (Momo's Four Seasons)

계절마다 옷을 갈아입는 곰 인형 캐릭터 '모모'를 소개하는 인터랙션 웹사이트 포트폴리오입니다.
첫 무대는 화면에 고정된 채 장면만 바뀌다가, 마지막 장면에서 더 내리면 아래로 스크롤되며 인스타그램 구간이 이어집니다. 첫 화면에서 고른 계절이 페이지 끝까지 색과 이미지를 정합니다.

> 포트폴리오용 가상 캐릭터 사이트입니다. 굿즈는 실제로 판매하지 않으며, 인스타그램 구간은 사이트 이미지로 꾸민 미리보기입니다.

## 기획 의도

- 기존 캐릭터 소개 페이지의 문제: 이미지, 설정표, 굿즈 목록이 아래로 길게 이어져 캐릭터를 느끼기 전에 스크롤만 하다 나가게 됨
- 방향: 캐릭터를 한 화면에 세우고 계절을 갈아입힌다. 화면은 그대로, 내용만 바뀐다
- 핵심 경험: 첫 화면에서 계절을 고르고, 모모가 갈아입는 모습을 보고, 눌러서 반응을 본다
- 이어지는 경험: 고른 계절이 소개, 사진첩, 인스타그램 피드까지 따라간다

```
첫 화면 (계절 고르기) → 모모 소개 → 굿즈 → 사진첩 → 이야기
        ↑ 고른 계절이 모든 장면의 색과 이미지를 정한다
```

## 계절 모모

| 계절 | 옷과 소품 | 한마디 |
|---|---|---|
| 봄 | 분홍 보닛, 노란 가디건, 벚꽃 가지 | 벚꽃 보러 같이 갈래? |
| 여름 | 밀짚 보닛, 선글라스, 꽃무늬 셔츠, 수박바 | 수박바는 양보 못 해. |
| 가을 | 머스터드 보닛, 트렌치코트, 커피 | 커피 한 잔 들고 좀 걷자. |
| 겨울 | 털 보닛, 목도리, 털부츠, 선물 | 네 선물도 준비했어. |

털, 분홍 볼, 턱 아래 리본 매듭은 계절이 바뀌어도 그대로 둡니다. 네 이미지를 같은 구도로 만들어, 계절을 바꾸면 제자리에서 옷만 갈아입은 것처럼 보입니다.

## 화면 구성

| 장면 | 내용 |
|---|---|
| 인트로 (스크롤) | 흑백 MOMO'S FOUR SEASONS와 기본 모모에 색이 입혀지고(글자는 위에서 아래로, 모모는 털모자에서 원으로), 가운데 십자가 회전하며 빨강 → 흰색. 모모에서 기본 모모 배경색이 퍼진 뒤, 화면이 아래로 내려가는 동안 모모가 따라 내려와 첫 무대 모모 자리에 도착(도착하면 1초 잠금) |
| 첫 화면 | 처음엔 기본 모모(빨간 털모자), 화살표로 봄·여름·가을·겨울. 계절 모모일 땐 여기가 맨 위(기본 모모로 돌아와야 인트로로 올라감). 계절 이름과 한마디, 가운데 모모, 떠다니는 소품 6개, 계절 전환 버튼 |
| 모모 소개 | 모모가 왼쪽 칸으로 떨어져 앉고, 오른쪽에 프로필과 "모모를 알아보는 네 가지" |
| 굿즈 | 인형, 키링, 머그 등 5종. 소개에서 넘어오면 모모는 제자리에서 사라지고 바로 굿즈. 기본 모모일 때만 나오고, 계절 모모는 소개 다음 바로 인스타그램으로 |
| 인스타그램 (스크롤) | 액자가 커지고 뽀글 털이 화면을 덮은 뒤, 외곽선 momo 글자 위로 지금 계절 카드 9장이 날아옴 |
| 계정 카드 | @momo_bearstudio 소개, 계절을 누르면 첫 화면으로 올라가 그 계절로 |
| 이야기 (스크롤) | 계절마다 하나씩 하는 일, 팔로우 안내, 푸터 |

## 주요 기능

- **계절 전환**: 화살표, 점, 키보드, 스와이프로 전환. 화면이 1.38배 커지며 -14° 도는 사이 모모가 옷을 갈아입고, 소품 6개가 계절마다 정해진 자리로 이동
- **장면 전환**: 휠, ↑↓ 키, 세로 스와이프, 메뉴로 이동. 장면 안에 더 읽을 내용이 있으면 그 안에서 먼저 스크롤. 굿즈 장면에서 더 내리면 페이지 스크롤
- **스크롤 연출**: 인스타그램 구간은 화면에 고정(sticky)된 채 스크롤 진행도에 맞춰 액자 확대 → 털 → momo → 카드 순으로 진행
- **카드 옮기기**: 마우스로 카드를 집어 테이블 위에서 옮길 수 있음
- **모모 착지 · 점프**: 소개 장면으로 가면 모모가 위에서 떨어져 정착, 첫 화면에서 모모를 누르면 폴짝
- **마우스 패럴랙스**: 소품이 크기(깊이)에 비례해 마우스 반대쪽으로 움직임
- **계절 따라가기**: 소개, 인스타그램 카드, 계정 카드, 배경색이 `data-season` 속성 하나로 함께 바뀜
- **반응형**: 데스크톱, 모바일 대응
- **접근성**: 키보드 조작, 모션 줄이기(`prefers-reduced-motion`) 설정 대응

## 폴더 구조

```
momo-seasons/
├─ index.html   화면 구조 (첫 무대 장면 3개 + 스크롤 구간)
├─ style.css    스타일, 장면 전환, 계절별 이미지
├─ script.js    계절 전환, 장면 전환, 소품 배치, 스크롤 연출, 카드 끌기
├─ img/         계절별 이미지 (spring/ summer/ autumn/ winter/), 굿즈
└─ docs/        기획서 PDF, 피그마 프로토타입 제작 노트
```

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 글꼴은 인터넷 연결이 필요합니다.
